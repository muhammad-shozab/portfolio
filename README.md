## ✨ Features

- 🌌 **Three.js Particle Sphere** — interactive mouse-repulsion effect in the hero
- 🃏 **3D Flip Cards** — capability cards with front/back reveal on hover
- 🔮 **Physics Skill Orbs** — canvas-based orb simulation with mouse attraction & collision
- ⌨️ **Animated Terminal** — typewriter-style code showcase
- 🎯 **Custom Cursor** — crosshair + glowing ring with hover states
- 🔄 **Infinite Carousels** — toolkit and testimonials auto-scroll
- 📅 **3D Timeline** — scroll-driven parallax journey section
- 📊 **Animated Skill Bars** — intersection-observer triggered fill animations
- 📱 **Fully Responsive** — mobile, tablet & desktop
- ⚡ **Zero Dependencies** — no frameworks, no build tools, pure vanilla

## 🚀 Running Locally

No build step required:

```bash
# 1. Clone the repo
git clone https://github.com/muhammad-shozab/portfolio.git

# 2. Open the folder
cd portfolio

# 3. Open in browser
# Option A — just double-click index.html
# Option B — use VS Code Live Server (recommended for hot reload)
```

| Structure | HTML5 (semantic, accessible) |
